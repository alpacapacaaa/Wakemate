# Wakemate

친구 몇 명이 한 방에 모여 함께 일어난다. 각자 자기 시각에 깨는데, **다른 친구가 녹음해둔 목소리**로
깨어난다. 아침이 지나면 방에는 **모닝 로그**가 남는다 — 누가 몇 시에 일어났고, 누구 목소리로
일어났는지.

그 전에, 평범한 알람 앱으로서 제대로 동작해야 한다 (알람 여러 개, 요일 반복, 스누즈).

```
frontend/   iOS 앱 — Expo SDK 57 + React Native, AlarmKit 네이티브 모듈. iOS 26 전용
backend/    서버 — 아직 없다. 계약은 docs/ 에 다 있다
docs/       MVP.md(범위) · api-contract.md(계약) · openapi.yaml · alarmkit.md(네이티브 검증 기록)
```

## 어디서부터 읽나

1. **`docs/MVP.md`** — v1에 무엇이 들어가고 무엇이 안 들어가는지. 다른 문서와 어긋나면 이게 이긴다.
2. **`docs/api-contract.md`** — 서버가 무엇을 답해야 하는지, 그리고 *왜*. `docs/openapi.yaml`이
   같은 내용의 기계용 버전이다.
3. **`docs/alarmkit.md`** — 알람이 실제로 울리는 부분. 공식 문서에서 확인한 API 사실과, 실기기에서만
   답이 나오는 항목들.
4. **`CONTRIBUTING.md`** — 앱을 실행하는 방법. `expo run:ios`는 이 프로젝트에서 동작하지 않는다.

## 지금 상태

앱은 화면이 전부 있고 로컬 저장소(`frontend/lib/store.ts`, AsyncStorage)가 서버를 대신한다. 그
파일은 처음부터 async에 API 모양이라 **실제 엔드포인트가 생기면 그 파일 하나만 교체하면 되고 화면은
손대지 않아도 된다.**

서버가 없어서 아직 안 되는 것: 초대 코드로 친구가 실제로 참여하는 것, 친구가 일어났는지 아는 것,
"내일 아침은 이 친구 목소리"를 방 전체가 같은 답으로 아는 것. 세 개 다 `docs/MVP.md`에 있다.

**알람이 실기기에서 울리는 것은 아직 한 번도 확인되지 않았다.** 시뮬레이터는 예약을 받아주지만 울리지
않는다.
